
🐍 Analyse et nettoyage des données de stocks avec Python

## 🎯 Objectif

Analyser un jeu de données de stocks afin d’identifier les anomalies, les valeurs manquantes et les données incohérentes, puis préparer les données pour l’analyse.

## 🏢 Contexte

Ce projet consiste à exploiter des données de stocks à l’aide de Python afin de contrôler leur qualité et d’obtenir des informations utiles à l’analyse.

L’objectif est de mettre en œuvre différentes étapes de préparation, de nettoyage et d’exploration des données.

## 🛠️ Outils utilisés

- Python
- Pandas
- Jupyter Notebook

## 🔎 Méthodologie

- Importation du jeu de données
- Exploration des données
- Vérification de la structure et des types de données
- Identification des valeurs manquantes
- Recherche des valeurs incohérentes
- Identification des prix négatifs
- Analyse des valeurs aberrantes
- Nettoyage et préparation des données
- Analyse statistique des données
- Vérification de la qualité des données après traitement

## 📊 Analyses réalisées

- Exploration des différentes variables
- Analyse des stocks
- Identification des valeurs manquantes
- Recherche des prix négatifs
- Analyse des valeurs aberrantes
- Contrôle des données incohérentes
- Calcul d’indicateurs statistiques

## 📈 Résultats

Le traitement permet d’identifier et de corriger différentes anomalies présentes dans les données afin d’obtenir un jeu de données plus propre et exploitable pour l’analyse.

Cette étape de préparation facilite ensuite l’analyse des stocks et l’interprétation des résultats.
